The actual production path remains:

1. Sonarr queries Prowlarr → AniBridge → metadata API.
2. Sonarr performs the sole `POST /release`, which calls AniBridge's real

3. Normal `app.main` lifespan starts `Runner`/`SubprocessExecutor`.
4. Actual `job_child` resolves the synthetic offers with the maintained parser,
   streams bytes through production yt-dlp transport and reports progress.
5. Actual remux/probe/receipt children verify and publish the MKV; production
   `Jobs.finish` records completion. No fabricated outcome or DB status update.
6. Sonarr's completed-download handling imports it through the shared path.

No restart or retry is needed for this single happy-path case. If a job blocks/
fails or import fails, this run fails: retain diagnostics and stop. Do not force
completion, copy media into the library, introduce a fallback or broaden tests.

  -v anibridge-query-bunny-pilot_local-state:/retained:ro --entrypoint python \
  anibridge-query-api:0ce826fd30eba0cf8c0772a53e0695331028feb0 - <<'PY'
import json, shutil, sqlite3, tempfile
from pathlib import Path
with tempfile.TemporaryDirectory() as temporary:
    for suffix in ('', '-wal', '-shm'):
        source = Path('/retained/anibridge_jobs.db' + suffix)
        if source.exists():
            shutil.copy2(source, Path(temporary) / source.name)
    with sqlite3.connect(Path(temporary) / 'anibridge_jobs.db') as db:
        rows = db.execute('SELECT j.status FROM clienttask c LEFT JOIN job j ON j.id=c.job_id').fetchall()
